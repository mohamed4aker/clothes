## التشغيل

### المتطلبات
- .NET 8 SDK
- SQL Server (Express أو LocalDB)
- Visual Studio 2022 (موصى به)

### خطوات التشغيل
1. افتح `MAS.sln` في Visual Studio
2. اضغط F5
3. سيتم إنشاء قاعدة البيانات تلقائياً
4. سجّل الدخول:
   - **Email**: admin@zaid.com
   - **Password**: Admin@123

### تحديث قاعدة البيانات بعد إضافة جداول جديدة
عند إضافة جداول جديدة في الكود، احذف قاعدة البيانات القديمة:
1. اقفل المشروع
2. SQL Server Object Explorer → MAS_DB → Delete
3. علم على "Close existing connections"
4. F5 لإعادة التشغيل
